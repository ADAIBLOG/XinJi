# 薪迹 Xinji

简洁的工资记录应用，为打工人生成的每一笔收入都清清楚楚。

**无广告 · 无内购收费 · 无追踪器**

- **无广告**：没有任何形式的广告与推广内容
- **无收费**：全部功能免费开放，没有付费解锁、没有会员
- **无追踪器**：不收集、不上传任何数据——应用甚至**没有申请网络权限**（见 `android/app/src/main/AndroidManifest.xml`，仅使用通知、闹钟、开机恢复与电池优化白名单四个本地权限），数据全部存储在你的手机本地

## 功能

### 记工资
- **三种计薪模式**：时薪（按打卡工时）、日薪（按出勤天数）、月薪（按 21.75 或当月实际天数折算，排班休息日与节假日不扣薪）
- **多工作**：可同时记录多份工作，每份工作独立的薪资、排班、打卡与个税设置，按标识色区分
- **加班**：手动记加班 + 固定上班时间自动记加班（当日超出标准工时的部分），独立加班时薪
- **个税扣除**：月起征点 + 单一税率近似计算，按月整体生效

### 打卡
- **上下班打卡**：精准模式两次打卡闭合时段，简洁模式一键打卡
- **跨天夜班**：夜班时段可按午夜分割分摊到两天，或整段归入下班日期（可配置）
- **打卡提醒**：为每份工作自定义多个提醒时间点，系统闹钟到点弹出通知（应用被杀后仍可触发）；被系统拦截时，应用运行期间会补发 15 分钟内错过的提醒；点击通知可直接回到今日页打卡

### 看数据
- **日历**：逐日状态一览（上班 / 加班 / 休息 / 请假 / 缺勤），可切换显示工时或工资金额，支持手动标记休息、请假
- **统计**：本周 / 本月 / 今年 / 累计收入，每日收入柱状图（多工作按标识色堆叠），加班工时与加班费统计，点击日期查看当日明细
- **组件自定义**：统计页各组件的显示与排序、今日页收入卡标签，均可自由配置
- **桌面小组件**：今日打卡小组件，桌面一键打卡

### 其他
- 深色模式、OLED 纯黑省电模式、多主题色
- 休息日排班：无固定 / 每周固定休息 / 大小周
- 数据本地 JSON 持久化，卸载前可自行备份（应用数据目录）

## 下载

前往 [Releases](../../releases) 下载最新版 APK（arm64-v8a），安装即可使用。

支持 Android 8.0+。

## 隐私

薪迹不需要注册、不需要登录、不联网。你的所有数据（工作设置、打卡记录、日历标记）只存在于你手机的应用私有目录中，卸载应用即随之删除。应用使用的全部系统权限：

| 权限 | 用途 |
| --- | --- |
| 通知 | 打卡提醒到点弹出 |
| 精确闹钟 | 应用被杀后仍能按时触发打卡提醒 |
| 开机完成 | 重启手机后恢复已排定的每日提醒 |
| 电池优化白名单 | 避免系统冻结后台闹钟（可选，可在系统弹窗中拒绝） |

## 技术栈

[Flutter](https://flutter.dev) 构建，仅面向 Android。通知使用 [flutter_local_notifications](https://pub.dev/packages/flutter_local_notifications)。内置字体为开源的 [Figtree](https://fonts.google.com/specimen/Figtree)（SIL OFL 1.1 授权，许可文本见 [assets/fonts/OFL.txt](assets/fonts/OFL.txt)），中文文本回落系统字体。

```bash
# 本地构建
flutter pub get
flutter build apk --release --target-platform android-arm64
```
